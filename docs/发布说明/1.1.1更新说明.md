# GBaseLite 1.1.1 更新说明

本次发布汇总自上次已提交版本以来的全部开发改动，包含 MVCC、SQL 执行优化、MySQL 客户端兼容和 Windows 部署修复。GBaseLite 仍是 MySQL 兼容子集；新增实验能力不等于完成生产级数据库认证。

## 主要更新

- **Navicat 连接与元数据**：补齐虚拟 information_schema 的 USE、系统表浏览、字段和索引描述；新增 CHARACTER_SETS、COLLATIONS、ENGINES 查询。修复 NDB 引擎探测的预处理 SQL；不存在的 NDB/InnoDB 返回 0，不冒充其他引擎。
- **并行数据传输**：实现会话级 FOREIGN_KEY_CHECKS，允许关闭检查的工作连接乱序建表及写入，同时保存外键定义。支持开关保存/恢复、连接重置、后续写入检查；MVCC 持久化反向依赖保证父表晚建后仍可检查引用。
- **事务与存储**：新增可选 MVCC 后端、行版本和冲突检测、磁盘暂存写集、顺序 WAL、大事务原子发布、紧凑行/整数主键编码、分页存储和冷读支持。MVCC transaction_write_mb=0 不限制逻辑写集总量，缓冲仍有界。
- **查询与 SQL**：扩展普通/唯一/联合二级索引、覆盖读取、执行计划与 EXPLAIN、索引选择、JOIN、聚合、排序和 LIMIT 路径；增加外部排序、批量读写和查询资源预算。加入 JSON 函数、精确 DECIMAL、SAVEPOINT、ALTER 与约束相关实现及测试；不同存储模式支持范围见 README。
- **资源管理**：增加查询超时、结果/排序/临时空间限制、事务写集限制、Windows 工作集控制、预处理缓存边界及内存采样工具。资源上限不能保证 CPU、内存与 I/O 同时下降。
- **复制与维护**：新增实验性三节点 Raft、自动选主、复制追赶、固定连接代理，以及 MVCC GC、备份和布局迁移相关能力。默认仍为单机；高可用与空间回收仍有明确限制。
- **Windows 安装与恢复**：修复原子文件替换及快照异常处理，新增损坏候选检查与服务失败事件日志。MSI 对已明确识别的旧快照损坏提供双重确认的重建流程；默认保留数据，静默安装不自动删除。
- **文档与验证工具**：使用文档和报告分目录，增加 Java/JDBC 兼容测试、资源与四数据库对比工具、10/1,000/10,000/100,000/1,000,000 行报告和图表。报告保留 2026-09-08 的源码与环境证据，不能作为 1.1.1 全部新改动的性能测量。

## 升级与兼容注意事项

1. 升级默认保留原配置、账户、数据与日志；不要为修复 SQL 兼容问题选择重新初始化数据。
2. 并行导入需要每个工作连接执行 SET FOREIGN_KEY_CHECKS=0，完成后恢复为 1。其他连接保持检查；重新启用不会追溯扫描此前导入的行。GLOBAL 开关尚不支持。
3. 含关闭外键检查状态的逻辑 binlog 使用版本 3，旧程序不能重放。旧版本 1/2 的日志仍可读取。
4. MVCC 应使用全新目录或文档规定的迁移流程，不能直接切换旧库配置。跨库外键、复杂元数据 JOIN、存储过程等仍不属于完整兼容承诺。
5. Navicat 多语句初始化探测仍可能失败并回退到逐条执行；本次修复其已捕获的独立查询。尚未覆盖全部 Navicat GUI 功能。
6. 现有对比结果不支持“全面优于 SQLite”或“已满足海量生产数据库”的结论。
