# GBaseLite

使用 Go 编写的轻量级数据库服务，通过 MySQL 协议连接客户端。默认单机运行，提供可选的实验性 MVCC 和 Raft 复制能力；不是完整 MySQL 替代品。

## 1.1.1 更新

- 修复 Navicat information_schema 浏览、字段/索引描述和 ENGINES 预处理探测。
- 实现会话级 FOREIGN_KEY_CHECKS，支持多个连接并行乱序导入并保留外键定义。
- 汇总 MVCC、磁盘暂存写集、顺序 WAL、索引/执行计划、JSON/DECIMAL、查询资源预算及备份维护能力。
- 改进 Windows 安装诊断、损坏快照保护、文档及数据库对比工具。

[完整更新说明](https://github.com/pucj0/gbaselite/releases/tag/v1.1.1) · [配置与限制](https://github.com/pucj0/gbaselite/blob/master/README.md)

## 使用

```sh
docker pull pucj/gbaselite:1.1.1
```

支持 linux/amd64、linux/arm64。使用仓库 docker 目录中的 Compose 模板，复制 temp.env.example 为本地 temp.env 并设置强密码后启动：

```sh
docker compose --env-file docker/temp.env -f docker/docker-compose.yml up -d
```

将数据与日志目录持久化挂载，详见仓库文档。升级保留已有数据，不要启用重新初始化。

## 兼容限制

并行导入时各工作连接应分别关闭外键检查，并在完成后恢复；恢复不会追溯扫描历史数据。含该会话状态的 binlog 使用版本 3，旧程序不能重放。MVCC 不可直接通过切换配置接管旧格式数据；生产使用前必须验证实际业务 SQL、备份恢复和资源配置。现有实测不支持全面优于 SQLite 或已通过海量生产场景验证的结论。
